# lm-evaluation-harness - LLM Benchmarking

The lm-evaluation-harness is a standard tool for evaluating large language models across 60+ academic benchmarks, including MMLU, GSM8K, and HumanEval. Installation is straightforward with `pip install lm-eval`, and users can evaluate HuggingFace models with a simple command structure. The tool supports various workflows: standard benchmark evaluation for model releases, tracking training progress across checkpoints, comparing multiple models side-by-side, and using vLLM backend for faster inference (5-10x speed improvement). Key benchmarks include reasoning tasks (MMLU, GSM8K, HellaSwag, TruthfulQA), code generation (HumanEval, MBPP), and science questions (ARC). Results are saved in JSON format with metrics like accuracy and exact match scores. The tool is industry-standard, used by EleutherAI, HuggingFace, and major research labs, with GPU requirements ranging from 16GB for 7B models to 28GB for 13B models. Common issues addressed include slow evaluation (use vLLM), out-of-memory errors (reduce batch size or use quantization), and unexpected results (verify fewshot count and task names).
